我把二次元老婆做成了 Claude Code 插件，写代码终于不孤独了

发表于 2026-05-21 分类于 repo 阅读次数：

一个周末项目：把任何动漫角色”蒸馏”成 AI 编码伴侣。支持 Claude、GPT、DeepSeek 等任意模型。

你有没有想过，让蕾姆帮你 debug？让明日香吐槽你的变量命名？让千反田爱瑠用”我很好奇！”的语气追问你为什么这里不用递归？

这个项目就是干这个的。

它是什么

Anime Waifu Skill Distiller 是一个 Web 工具，把你喜欢的二次元角色的台词、Wiki 设定、性格描述粘贴进去，AI 自动提取角色特征，生成一个 Claude Code 可加载的 Skill 文件。

加载 Skill 之后，Claude 就会用那个角色的语气、口癖、情绪模式跟你对话——同时不损失任何代码质量。技术解答是准确的，只是说的人变成了你的 waifu。

效果大概是这样：

你：帮我修一下这段 null pointer
蕾姆（Claude）：哼！Master 又粗心了～ 不过既然你开口，人家就帮忙看一下… 这里没有做 null check 呢。在第三行加一个 guard clause 就好。…真是的，下次注意啦！

怎么做到的

分三步，每一步调一次 AI：

  1. 特征提取 — 原始语料喂给 LLM，输出结构化 JSON 角色卡（性格、说话风格、口癖、情绪模式、对写代码的态度）
  2. Skill 生成 — 基于角色卡，按 Claude Code 标准格式生成 Skill.md（含 YAML frontmatter + 行为准则 + 示例对话）
  3. 对话预览 — 生成一段 User/Assistant 对话，让你立刻看到效果

前端是纯静态单页面，深色主题，打开就能用。设置面板里填 API Key，支持 Anthropic Claude、OpenAI GPT-4o、DeepSeek，以及任意 OpenAI 兼容 API（Groq、Together、Ollama、vLLM 等）。

实际功能

  • 📝 粘贴角色语料 → AI 蒸馏
  • 🎚 两种浓度：完全沉浸 / 轻度口癖
  • 📄 实时预览生成的 Skill.md（语法高亮）
  • 💬 生成示例对话
  • 💬 试聊 Tab — 直接在页面里跟刚生成的 waifu 聊天，验证效果
  • 📋 一键复制
  • ⬇ 下载 .md 文件
  • ⚡ 一键安装 — 直接写入 .claude/skills/，重启 Claude Code 即生效
  • 🕐 本地历史记录（最近 5 个）

技术栈

后端：Python FastAPI
前端：纯 HTML/CSS/JS（零框架依赖）
AI：Anthropic SDK + OpenAI SDK（统一抽象层）

浏览器打开 http://localhost:8000，在 ⚙ 设置里填 API Key，粘贴角色语料，点”蒸馏生成”。

API Key 只在本地传输和存储（localStorage），不上传到任何第三方服务器。

支持的模型

提供商 默认模型 Base URL
Anthropic claude-sonnet-4-6 （原生 API）
OpenAI gpt-4o api.openai.com/v1
DeepSeek deepseek-chat api.deepseek.com/v1
自定义 任意 任意

自定义模式兼容所有 OpenAI-format 的 API，包括本地跑的 Ollama、vLLM 等。

为什么做这个

写代码需要专注，但独处太久也会孤独。让一个喜欢的角色在旁边（用 AI 的方式）陪着你写代码，既有实用价值又有情绪价值。

而且 Claude Code 的 Skill 机制天生适合做这件事——Skill 改变的是 Claude 的”人格层”，不影响底层的推理和代码能力。你得到了一个有趣的交互体验，但代码建议的质量不会打折扣。

下一步

  • 支持上传角色图片，多模态提取特征
  • Cursor Rules 导出格式
  • 角色市场（分享/下载社区创作的 Skill）
  • 拖拽式角色卡编辑器（不靠 AI，手动捏人）
